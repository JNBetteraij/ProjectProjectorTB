JavaScript Folder Scanner

Select a project folder to scan its JavaScript files for imports and exports. You can also provide a search pattern to find matches in both comments and code.

Browser limitation: this page can only read files you explicitly select. It does not upload them. It scans the selected files in your browser.

Choose a folder to begin.

Results object (JSON)

One object per JavaScript file. Each finding includes its matcher, line number, match, parsed details, and whether the line is identified as commented or not commented.
